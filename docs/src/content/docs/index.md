Create Python App (CPA) is a guided command-line wizard for creating new Python projects.

CPA helps you get from:

> "I have an idea"

to

> "I'm writing code"

as quickly as possible.

Instead of manually creating folders, configuring virtual environments, setting up editor integrations and creating starter files, CPA does the repetitive work for you.

## Features

- Guided setup wizard
- Virtual environment creation
- Modern Python project structure
- VS Code support
- Optional editor plugin installation
- Generated documentation
- Simple, beginner-friendly workflow

## Getting Started

- Install CPA
- Create a project
- Start coding

See the Getting Started section to learn more.
