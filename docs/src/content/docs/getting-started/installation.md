Create Python App can be installed using Python's package manager.

## Requirements

Before installing Create Python App, ensure you have:

- Python 3.10 or later installed.
- A supported terminal environment.

You can verify your Python version using:

```bash
python --version
```

## Install from PyPI

Once Create Python App is publicly available, install it with:

```bash
pip install createpythonapp
```

## Verify Installation

Run:

```bash
create-python-app
```

If installation was successful, the Setup Wizard will be displayed.

## Upgrade

To upgrade to the latest version:

```bash
pip install --upgrade createpythonapp
```

## Uninstall

To remove Create Python App:

```bash
pip uninstall createpythonapp
```

## Troubleshooting

### Command not found

If:

```text
create-python-app
```

is not recognised, ensure that Python's Scripts directory is available on your system PATH.

### Python version issues

Create Python App requires Python 3.10 or newer.

Verify your Python version with:

```bash
python --version
```

### Virtual environments

Create Python App automatically creates project-specific virtual environments during project setup. No additional configuration is required.
